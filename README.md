## AI Project Source Codes:

* [Titanic Survivor](https://github.com/10pt/MystanCodeProjects/tree/main/stanCode_AI_Projects/TitanicSurvivor)
 * Train a model to predict the survival rate of passengers on the Titanic.

* [Boston Housing](https://github.com/10pt/MystanCodeProjects/tree/main/stanCode_AI_Projects/BostonHousing)
 * Build a regression model that predicts housing prices based on various factors like location, number of rooms, and socioeconomic status of the neighborhood.

* [102 Catergory Flower](https://github.com/10pt/MystanCodeProjects/tree/main/stanCode_AI_Projects/102%20Category%20Flower)
 * In this project, a pre-trained ResNet18 model is fine-tuned to classify images of flowers into 102 categories. The focus is on achieving a high classification accuracy through transfer learning techniques.

* [CIFAR10 Classification](https://github.com/10pt/MystanCodeProjects/tree/main/stanCode_AI_Projects/CIFAR10)
 * This project involves building a neural network to classify images from the CIFAR10 dataset into 10 distinct classes. The model is designed to handle the challenges of multiclass classification and aims to achieve high accuracy.
